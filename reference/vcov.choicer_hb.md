# Posterior covariance of the population coefficients

Posterior covariance of the population coefficients

## Usage

``` r
# S3 method for class 'choicer_hb'
vcov(object, ...)
```

## Arguments

- object:

  A `choicer_hmnl` or `choicer_hmnp` object.

- ...:

  Additional arguments (ignored).

## Value

K x K posterior covariance matrix of the b draws.
