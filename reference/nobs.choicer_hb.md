# Number of choice situations behind a hierarchical Bayes fit

Number of choice situations behind a hierarchical Bayes fit

## Usage

``` r
# S3 method for class 'choicer_hb'
nobs(object, ...)
```

## Arguments

- object:

  A `choicer_hmnl` or `choicer_hmnp` object.

- ...:

  Additional arguments (ignored).

## Value

Integer count of choice situations (tasks).
